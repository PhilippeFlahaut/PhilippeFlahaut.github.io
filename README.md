# Philippe Flahaut — Site officiel

GitHub Pages website for Philippe Flahaut.

## Upload to GitHub

Upload the **contents of this folder** to the root of:

`PhilippeFlahaut/PhilippeFlahaut.github.io`

The repository should contain:

- `index.html`
- `css/style.css`
- `js/main.js`
- `assets/images/`
- `.nojekyll`

## Images

Drop final images into `assets/images/` using these exact names:

- `hero.jpg` — main full-screen homepage photo
- `portrait.jpg` — artist portrait in the About section
- `story.jpg` — image for the “Histoires en chansons” section
- `latest-release.jpg` — latest single / release artwork

The site will still display styled placeholders if those images are missing.

## Content to replace

Open `index.html` and replace:

- placeholder song titles
- Spotify URLs
- Instagram / YouTube / Linktree URLs
- latest release text
- biography

## Publish

Because the repository is named `PhilippeFlahaut.github.io`, the site should be available at:

https://philippeflahaut.github.io

If it is not published automatically:

**Repository → Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/ (root)`**
